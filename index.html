⚙   How it works
  1. Select a date and time.
  2. Choose the timestamp format.
  3. Copy the generated code.
  4. Paste it into Discord.
  5. Discord displays the time in each recipient’s local timezone.
Discord timestamps use Unix time (seconds since January 1, 1970). This tool automatically converts the date and time into the correct Unix timestamp.
